# Geom variations

Practice common `ggplot2` geometry layers using the built-in `mpg` dataset.
Install `ggplot2` first by following
[01-installing-packages](../01-installing-packages/README.md).

Run from the repository root:

```sh
Rscript assignments/03-geom-variations/practice.R
```

The script prints several plots in an interactive R session.
